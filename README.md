# שוסטר פארק 🎢

פארק שעשועים שלם בדפדפן, בטלפון ובמחשב.

**לשחק:** https://raw.githack.com/shuster-dev/ShusterPark-/site/index.html
 בונים רכבות הרים חלק אחרי חלק, מציבים מתקנים ודוכנים, מתמחרים כרטיסים, מעסיקים מנקים, מכונאים ובדרנים, ושומרים על המבקרים מרוצים. הפארק נשמר לבד בדפדפן.

## מה יש

- **מתחילים בקופה:** בלי קופה הפארק סגור. מציבים אותה ליד הכניסה, ובה קובעים את מחיר הכניסה ואת המחיר של כל מתקן ודוכן, עם כפתור למחירים מומלצים.
- **הדרכה קצרה:** שלושה צעדים (קופה, שבילים, מתקן ראשון) ואז הכל בידיים של השחקן. אפשר לדלג.
- **רכבות הרים:** מציבים תחנה ומחברים חלקים מוכנים: ישר, פניות, עליות וירידות, מעלית שרשרת, צלילה, לופ ובלמים. כפתור "השלם" מחזיר את המסילה לתחנה לבד. בבדיקה הרכבת נוסעת באמת, ומקבלים מהירות, גובה, כוחות G וציון ריגוש, עוצמה וסחרחורת.
- **6 מתקנים:** קרוסלה, גלגל ענק, ספלים מסתובבים, מכוניות מתנגשות, ספינת פיראטים ומגדל נפילה. כולם זזים.
- **דוכנים:** המבורגר, פיצה, שתייה, גלידה, בלונים ושירותים.
- **אורחים:** עד 400 בבת אחת, אנשים עם ידיים ורגליים שזזות, חמש תסרוקות, ילדים ומבוגרים. רואים אותם נכנסים מהחניה, עומדים בתור, ויושבים על המתקנים עצמם. המנקה עם מטאטא, המכונאי עם קסדה וארגז כלים, הבדרן בתחפושת דובי.
- **אורחים, עוד:** לכל אחד כסף, רעב, צמא, עייפות, בחילה וטעם משלו בעוצמה. הם מוותרים על מתקן יקר מדי, מתלוננים על לכלוך ותורים ארוכים, משאירים אשפה ולפעמים מקיאים. אפשר ללחוץ על כל אורח ולראות מה עובר לו בראש.
- **צוות:** מנקים שמחפשים את הלכלוך הקרוב, מכונאים שמתקנים תקלות ובודקים מתקנים, ובדרנים שמשמחים ומקצרים את ההמתנה.
- **כסף:** הלוואה, ריבית, משכורות, תחזוקה, דמי כניסה, קמפיין פרסום ודוח חודשי.
- **נוי:** עצים, פרחים, פסלים ומזרקה, ולשביל ספסלים, פחים ופנסים.
- **יעד:** 250 אורחים ודירוג 600 עד מרץ בשנה השלישית. אחרי זה ממשיכים כמה שרוצים.
- **שליטה:** בטלפון אצבע אחת מזיזה ושתיים מזמזמות ומסובבות. במחשב גרירה, גלגלת, כפתור ימני לסיבוב, WASD, Q/E, R לסיבוב מתקן ורווח להשהיה.

## הרצה מקומית

```bash
npm install
npm run dev          # http://localhost:5173
```

## בדיקות

```bash
npm run qa           # חוקי המשחק: מסילות, פיזיקה, ציונים, כסף, אורחים, שמירה
npm run balance      # פארק לדוגמה רץ שנתיים: האם הוא מרוויח והאם היעד בהישג יד
npm run test:browser # דפדפן אמיתי, טלפון ומחשב, עם צילומי מסך ב־shots/
```

## העלאה לאוויר

כל מיזוג ל־main בודק את החוקים, בונה את המשחק ושם אותו בענף `site`. הקישור למעלה מגיש את הענף הזה ישירות מ־GitHub, בלי שרת ובלי חשבון נוסף.

רוצים כתובת יפה יותר? ב־Settings → Pages בוחרים **Deploy from a branch**, ענף `site`, תיקייה `/`. המשחק יעלה גם ב־`https://shuster-dev.github.io/ShusterPark-/`. אפשר גם Render: **New → Blueprint** עם `render.yaml`.

## איך זה בנוי

- `src/sim/`: המשחק עצמו, בלי ציור, כך שהבדיקות מריצות שנים בשנייה.
  - `catalog.js`: כל המתקנים, הדוכנים, המחירים והמספרים במקום אחד.
  - `track.js`: חלקי המסילה, העקומה החלקה, נסיעת הבדיקה (פיזיקה לאורך המסלול), הציונים וההשלמה האוטומטית.
  - `park.js`: הקרקע, הבנייה, הכסף, הדירוג והשמירה. מפות מרחק לאורך השבילים מחושבות רק כשמשהו משתנה.
  - `guests.js`, `staff.js`: מה אורחים ועובדים עושים.
- `src/client/`: three.js. כל הדגמים נבנים בקוד, בלי קבצים להוריד. אנשים, עצים ושבילים מצוירים כמופעים (instancing), כך שמאות אורחים עולים כמעט כלום.
